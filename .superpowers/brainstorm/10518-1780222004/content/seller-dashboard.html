What can a driver/owner do with their listings?

This shapes how much we build on the seller side

A

View & Track Only (Recommended)

Sellers can see their listings with status (Pending / Approved / Sold), see how many inquiries came in, and mark a listing as Sold themselves. No editing after submission — if they need changes, they contact admin.

Pros

  • Simple to build
  • Admin stays in control of what's published
  • No re-approval logic needed

Cons

  • Sellers can't fix typos without calling admin
B

Full Management — Edit, Delete, Mark Sold

Sellers can edit their listing details and photos. Any edit on an approved listing sends it back to Pending for re-approval. They can also delete their own listings.

Pros

  • Sellers are self-sufficient
  • Better data quality

Cons

  • Significantly more code
  • Re-approval flow adds complexity
  • Delete means losing inquiry history
C

View + Mark Sold + Delete (No Edit)

Sellers see their listings and inquiries, can mark as Sold, and can delete (with confirmation). No editing — new listing required for changes.

Pros

  • Reasonable seller control without edit complexity
  • Cleaner than full management

Cons

  • Delete loses inquiry history
  • No fixing mistakes
