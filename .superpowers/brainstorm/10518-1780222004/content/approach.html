Where should drivers & owners manage their car listings?

Three approaches — pick the one that fits how your team operates

A

Fleet Portal (Recommended)

Add a "Used Cars" tab inside the existing fleet dashboard at driver.greenrides.co.in. Drivers and owners are already logged in there. One click to list a car — name/phone pre-filled from their profile. Admin creates listings from the existing admin panel.

Pros

  • No new login or URL
  • Pre-fills all contact info
  • Listings tied to their account
  • Sellers can see status + inquiries

Cons

  • Only fleet-registered users can list (public sell form still works for others)
B

Main App — Logged-in Seller Dashboard

Any user who logs in at greenrides.co.in via OTP gets a "My Listings" section under their profile. Drivers/owners use the same login as riders. Admin creates from their panel.

Pros

  • Works for any seller, not just fleet
  • Single app for everything

Cons

  • Riders and drivers share the same auth space — messy
  • More changes to the main rider app
C

Keep It Simple — Better Sell Form Only

Keep the existing public form at /used-cars/sell, but improve it: detect if the visitor is a logged-in driver/owner and pre-fill their details. Add a status-check page where sellers enter their phone to see their listing status. Admin gets a "Create Listing" button in the admin panel.

Pros

  • Least code change
  • Public still works for non-fleet sellers

Cons

  • No real account tie — anyone can check any number
  • No inquiry notifications to sellers
